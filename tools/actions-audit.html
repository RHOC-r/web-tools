ワークフローを貼り付けて、よくあるセキュリティ上の危険を確認します。

GitHub Actions安全監査とは

GitHub Actions YAMLの過剰権限、未固定Action、危険なシェル実行などを検出する無料ツールです。

使い方

左側の入力欄へ内容を貼り付け、実行ボタンを押してください。結果は右側に表示され、必要に応じてコピーまたは保存できます。

安全に使うために

処理はブラウザ内で行いますが、自動判定には限界があります。公開・本番反映の前には必ず結果を目視で確認してください。
