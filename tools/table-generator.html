CREATE TABLE文生成について

データベースのテーブル定義を 表形式で作成し、 SQLへ変換できます。

使い方

テーブル名を入力し、カラム名、データ型、サイズ、PRIMARY KEY、NOT NULL、 UNIQUE、AUTO INCREMENT、DEFAULTを設定して生成ボタンを押します。

対応するカラム制約

主キー、NULL禁止、一意制約、自動採番、デフォルト値を指定できます。 生成後のSQLは画面上で編集してコピーできます。 

CREATE TABLE users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE,
  created_at DATETIME
);
