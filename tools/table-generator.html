生成結果

CREATE TABLE文生成ツールについて

データベースのテーブル定義を表形式で入力し、 MySQLで使用できるCREATE TABLE文を生成するツールです。

入力した内容はブラウザ内で処理され、 サーバーへ送信されません。

使用例

テーブル名：users

id
INT
PRIMARY KEY
AUTO_INCREMENT

name
VARCHAR
サイズ：100
NOT NULL

email
VARCHAR
サイズ：255
UNIQUE

上記のように設定すると、 次のようなSQLを生成できます。 

CREATE TABLE users (
  id INT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255) UNIQUE
);
